# Sistem Manajemen Mahasiswa

Project Ujian Tengah Semester Mata Kuliah Pemrograman Web.

## Deskripsi
Aplikasi web sederhana untuk mengelola data mahasiswa menggunakan HTML, CSS, dan JavaScript.

## Fitur
- CRUD Data Mahasiswa
- Search Data
- Sorting Nama
- Pagination
- Dark Mode
- Show Password

## Teknologi
- HTML
- CSS
- JavaScript
